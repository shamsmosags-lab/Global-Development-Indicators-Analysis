# Global Development Indicators Analysis

A team-based data analysis project exploring economic, education, and healthcare indicators across Egypt, Nigeria, Turkey, and Pakistan from 2000 to 2015.

## Project Overview

This project uses Python, SQL, SQLite, Pandas, and Matplotlib to analyze and visualize development indicators across selected countries and years.

The analysis covers:

* Economic indicators
* Education indicators
* Healthcare indicators
